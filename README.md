# Векторный поиск по базе знаний Marvel

## Общая информация

### Модель эмбеддингов
intfloat/multilingual-e5-base — мультиъязычная модель SentenceTransformers (768-мерные векторы), запущенная локально в Codespaces без использования OpenAI API.

### База знаний
Для построения базы знаний были выполнены следующие действия:
1. C сайта marvel.fandom.com было взято 30 статей с описанием персонажей, технологий, событий и объектов из вселенной Marvel. Они сохранены в виде plain text без html-разметки в 30 текстовых документов.
2. С помощью скрипта build_dictionary.py был собран словарь уникальных терминов, которые определяют принадлежность текстов к вселенной Marvel. Для каждого термина сгенерировано выдуманное имя. Пары собраны в результирующий term_map.json в формате ключ-значение.
3. Полученный словарь был вручную отредактирован и доработан.
4. С помощью скрипта replace_names.py была выполнена замена в исходных текстах согласно словарю, сформированному на предыдущем шаге. Новые файлы были собраны в папку knowledge_base.

### Полученные тексты были предварительно обработаны:

* разбиты на логические чанки (~800 токенов, overlap 200);
* преобразованы в векторные представления;
* загружены в FAISS-индекс для быстрого поиска по смыслу.

## Параметры индекса

* Количество исходных документов: 30
* Количество сгенерированных чанков: 697
* Размерность эмбеддингов: 768
* Используемая метрика: cosine similarity
* Векторная база: FAISS (faiss.index + meta.jsonl)

## Производительность

* Генерация чанков: ~1–2 минуты
* Генерация эмбеддингов (локально на CPU): ~20–30 минут
* Построение векторного индекса: <1 минуты
